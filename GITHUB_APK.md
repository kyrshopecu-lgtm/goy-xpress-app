# Crear el APK de GOY XPRESS con GitHub

1. Crea un repositorio nuevo en GitHub llamado `goy-xpress-app`.
2. Descomprime este ZIP y sube todos los archivos y carpetas al repositorio.
3. Abre la pestaña **Actions**.
4. Selecciona **Generar APK GOY XPRESS**.
5. Pulsa **Run workflow** y confirma con el botón verde.
6. Espera aproximadamente 5 a 15 minutos.
7. Abre la ejecución terminada y descarga **GOY-XPRESS-APK** en la sección **Artifacts**.
8. Descomprime el archivo descargado para obtener `app-release.apk`.

El APK se puede instalar directamente en un teléfono Android. El teléfono puede solicitar permiso para instalar aplicaciones provenientes del navegador o del administrador de archivos.
